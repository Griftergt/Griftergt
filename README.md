## Выполнение
 

### 1. Включить отображение меню Grub
Меняем 2 параметра в конфигурационном файле.
GRUB_TIMEOUT_STYLE
GRUB_TIMEOUT
```bash
GRUB_DEFAULT=0
GRUB_TIMEOUT_STYLE=menu
GRUB_TIMEOUT=15
GRUB_DISTRIBUTOR=`( . /etc/os-release; echo ${NAME:-Ubuntu} ) 2>/dev/null || echo Ubuntu`
GRUB_CMDLINE_LINUX_DEFAULT=""
GRUB_CMDLINE_LINUX=""
```
